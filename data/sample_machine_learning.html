Machine Learning 101: Core Concepts

Supervised Learning

Supervised learning trains models on labeled input-output pairs to infer mappings. Common tasks include classification, which predicts discrete categorical labels, and regression, which predicts continuous numerical values.

Gradient Descent Optimization

Gradient Descent iteratively adjusts model parameters by computing the gradient of the loss function with respect to the weights. Learning rate determines step size along the negative gradient direction. Techniques such as Adam and RMSprop provide adaptive learning rates across iterations.
