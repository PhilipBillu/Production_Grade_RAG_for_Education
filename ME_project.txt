Techstack:

Backend - Python + FAST API
Ingestion - LlamaIndex parsers (pypdf, markdown, BeautifulSoup)
Lexical search - BM25 (rank_bm25 lib)
Sematic search - Local Weaviate docker
Hybrid search - Reciprocal Rank Fusion (RRF)
Reranking - cross-encoder/ms-macro-MiniLM-L-6-v2 (via hugging)
Embeddings - BAAI/bge-small-en-v1.5 (via hugging face sentence-transformers)
RAG framework - LlamaIndex
LLM(Baseline) - Groq API (Free Tier) - llama3-8b-8192
LLM(Fine-Tuned) - Ollama (Local) - llama3:8b-instruct-q4_K_M + LoRA Adapter
fine tuning - hugging face transformers + TRL
training compute - Google Colab (Free Tier) T4 GPU
parameter efficiency - PEFT(peft library + bitsandbytes)
Experiment tracking - local MLflow
Monitoring - local Promotheus docker + Grafana docker
LLM Logging - PostgreSQL(Indexing)
CI/CD gating - github actions(free tier)
database - PostgreSQL docker
